Robot Identity &
Memory Subnet

MemoryMesh AI gives every physical robot a persistent on-chain identity, verifiable task memory, and a live reputation score — powered by Proof-of-Physical-Work. Every action is a real blockchain transaction.

⛓ Fully Onchain via system.remarkWithEvent: Since the memorymesh pallet is not yet deployed on Konnex Testnet, all data is encoded as JSON and submitted as real system.remarkWithEvent extrinsics — these are genuine onchain transactions with real tx hashes you can verify in the explorer. Connect your Talisman/SubWallet wallet to sign transactions. tKNX balance required for fees.
Core Primitives
🆔
RobotID
Cryptographic on-chain identity derived from hardware fingerprint + owner address. Stored via memorymesh.registerRobot extrinsic. Immutable and portable.
🧠
MemoryStore
Append-only PoPW-verified task log. Each memory write is a memorymesh.writeMemory extrinsic confirmed on-chain. Miners read history to generate better policies.
⭐
ReputationScore
Weighted on-chain score updated after every verified PoPW event via memorymesh.updateReputation. Enterprises query live chain state before hiring robots.
⛏️
Memory-Enhanced Mining
Miners query memorymesh.getMemory(robotId) from chain storage to select optimal execution strategies from historical success patterns.
✅
PoPW Validation
Validators score robot execution and submit memorymesh.submitPoPW extrinsic. Scores are written on-chain permanently with block proof.
🔗
Cross-Subnet Utility
RobotID and MemoryStore can be consumed by Drone, RoboArm, and SLAM subnets via on-chain storage queries — creating compounding network value.
